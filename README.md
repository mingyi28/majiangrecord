# 麻将记分

手机上给一桌麻将记分。开一桌拿到 5 位数字房间号，每个人用记住的称呼选个头像坐下。记分时直接给每人填这一局的增减，几台手机看的是同一张账。结束前会先确认。

称呼存在这台手机的本地缓存里，下次进房会自动填上。开错房间时，开桌的人可以解散，记录仍留在管理端。

管理端在 `/#/admin`。本机第一次打开时设置口令，之后用它查看每桌分数和汇总。部署到 Vercel 时，在项目环境变量里设置 `ADMIN_TOKEN` 作为口令，并设置 Postgres 的 `DATABASE_URL`。之前线上只有页面、没有接口，所以会提示「没有连上牌桌」。

```bash
npm install
npm test
npm start
```

没有 `DATABASE_URL` 时，分数写在本机 `data/store.json`。配置 Postgres 后，启动时会执行 `migrations/`。
