# 麻将记分

手机上给一桌麻将记分。开房间后拿到醒目的 5 位数字房间号，每个人用记住的角色和头像坐下。记分时在弹窗里只能给其他玩家增加非负整数分，不能给自己加分，几台手机看的是同一张账。结束前会先确认。

角色存在这台手机的本地缓存里，可以切换角色、查看这台手机上的历史战绩并提交意见反馈。开错房间时，开桌的人可以解散，记录仍留在管理端。

管理端独立在 `/admin`，首页不显示入口。本机第一次打开时设置口令，之后可查看对局概览、每个人的战绩、天梯排行榜、逐局明细和意见反馈。部署到 Vercel 时，在项目环境变量里设置 `ADMIN_TOKEN` 作为口令，并设置 Postgres 的 `DATABASE_URL`。

```bash
npm install
npm test
npm start
```

没有 `DATABASE_URL` 时，分数写在本机 `data/store.json`。配置 Postgres 后，启动时会执行 `migrations/`。
