# 麻将记分

手机上给一桌麻将记分。首次打开且本机没有角色时，会直接弹出用户名和头像设置。开房间后拿到醒目的 5 位数字房间号，每个人用记住的角色和头像坐下；本机已有角色时，开房间会直接创建，输入房间号也会自动用该角色加入并坐下，不再重复填写资料。同一角色同时只能参加一个进行中的房间；回到首页仍能看到当前房间入口，以及带时间和状态的最近房间。记分时在弹窗里只能给其他玩家增加非负整数分，不能给自己加分。后台会把 1 分钟内多人提交的数据聚合成同一局，并在弹窗和对局列表显示结算倒计时；倒计时内再次记分会带回本人已填分数，结算后点击历史局修改则会留下标记。关闭房间后不再显示房间号，改为展示当天的最终结算。管理看板使用 `ADMIN_PASSWORD` 环境变量登录，并通过服务端 HMAC-SHA256 签名的 HttpOnly Cookie 保持 30 天会话。

角色存在这台手机的本地缓存里，可以切换角色、查看这台手机上的历史战绩并提交意见反馈。创建者会显示“房主”标记；分享按钮只分享 `/r/房间号` 形式的房间链接。通过分享链接首次进入且没有角色时，会先设置角色再自动加入。创建房间后会直接显示“关闭房间”和“记一局”；开错房间时直接关闭即可。

管理端独立在 `/admin`，首页不显示入口，可查看对局概览、每个人的战绩、天梯排行榜、逐局明细和意见反馈。部署到 Vercel 时，在项目环境变量里设置 `ADMIN_PASSWORD` 作为口令，并设置 Postgres 的 `DATABASE_URL`。修改 `ADMIN_PASSWORD` 会立即使已有管理会话失效。

```bash
npm install
npm test
npm start
```

没有 `DATABASE_URL` 时，分数写在本机 `data/store.json`。配置 Postgres 后，启动时会执行 `migrations/`。
